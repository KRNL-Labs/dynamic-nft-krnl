# Owner Portal

NFT owners log in, select the owner portal, and choose a brand. Demo mode grants default XP per wallet and brand so the full flow can be tested without a live Zealy account.

Owners can buy LootKeys with XP, open lootboxes, unlock traits, choose active traits, and submit active trait changes through the KRNL workflow path. The rendered NFT preview composites the brand base image with active trait layers.

Production XP comes from Zealy. Demo XP is local application state and should not be treated as production entitlement.
