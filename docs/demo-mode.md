# Demo Mode

Set `DEMO_MODE=true`.

Demo behavior:

- Owner wallets receive 10,000 default XP per selected brand.
- Live Zealy XP is not required to buy LootKeys or open lootboxes.
- KRNL workflow runs may be recorded as submitted or queued without live KRNL submission where the existing API code supports it.

Do not enable demo mode in production.
